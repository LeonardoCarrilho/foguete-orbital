# 🚀 Foguete Orbital

Jogo de reflexo em **JavaScript puro**: o foguete cai pela gravidade e você acelera para passar entre os campos de asteroides.

## Destaques técnicos
- Obstáculos criados e removidos dinamicamente como `div`s no DOM
- Física simples (gravidade e impulso) com `requestAnimationFrame`, independente da taxa de quadros
- Detecção de colisão por retângulos (`getBoundingClientRect`)
- Pontuação e recorde salvo no `localStorage`
- Controle por teclado (Espaço), mouse ou toque; layout responsivo

## Como rodar
Abra o `index.html` no navegador.

Desenvolvido a partir dos conceitos do módulo bônus de jogos em JavaScript do curso Full Stack Turbo (TipsCode).
